# FORGE - Workout & Exercise Tracking App

## 📌 Overview
FORGE is a powerful and intuitive workout tracking app that helps you log exercises, track workout progress, and analyze performance over time. Designed for efficiency and performance tracking, FORGE enables you to store workout data, monitor exercise history, and optimize training for strength and hypertrophy.

## 🔥 Features
- **Workout Logging**: Save and organize workout sessions.
- **Exercise Management**: Keep a database of exercises with relevant details.
- **Progress Tracking**: Monitor strength and hypertrophy improvements.
- **Stock Data**: Store past workout records for reference.
- **Intuitive UI**: Built for ease of use with a clean and simple interface.

## 🚀 Tech Stack
- **Frontend**: Nuxt3
- **Backend**: Strapi
- **Database**: PostgreSQL (Dockerized)
- **Deployment**: Digital Ocean
- **Styling**: TailwindCSS
